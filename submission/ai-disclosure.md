# AI use disclosure

This is the disclosure text prepared for the official submission form. The entrant must confirm that it accurately describes the actual workflow before submitting.

AI assistance was used for:

- drafting and debugging dependency-free HTML, CSS and JavaScript;
- suggesting concise interface copy, visual hierarchy and accessibility labels;
- checking the data pipeline, fallback export and that the narrative distinguishes descriptive comparison from causal claims.

The entrant reviewed and approved the research question, official datasets, countries, units, time windows, chart types, visual hierarchy, caveats and final wording. The entrant independently verifies all data, licences, claims and visual decisions before submission and retains responsibility for the final work. No AI-generated image is used as the final dataviz. This disclosure must be updated if the entrant’s actual workflow differs.
